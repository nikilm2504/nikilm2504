## 💳 PamaPay

Production-inspired digital payment platform backend built using Java and Spring Boot

### Tech Stack

| Layer | Technology |
|--------|------------|
| Language | Java 21 |
| Framework | Spring Boot |
| Database | PostgreSQL |
| Migration | Flyway |
| Build Tool | Maven |
